# 升学指南 · 考研与高考择校查询

一个响应式招生资料查询网站。提供考研、高考两个入口、学校与专业代码查询、学院和学习方式筛选、分数趋势、历年统计、官方招生公告以及来源说明。

[在线体验](https://yantu-admissions.referahmed134.chatgpt.site/) · [MIT 许可](LICENSE) · [第三方代码与数据来源](THIRD_PARTY_NOTICES.md)

## 公开使用

网站已设为公开访问，任何人可通过部署链接使用。查询不收集个人资料，无需创建本网站账号。

## 当前真实数据覆盖

- 全国普通高校完整名录：教育部 2026-06-18 公布、截至 2026-06-17 的全部 2,952 所普通高校，本科 1,412 所、高职专科 1,540 所，内地 31 个省级地区。支持关键词、学校标识码、地区和办学层次搜索，分页与键盘选择。数据来源与文件摘要保存于 `data/national-schools.json`。名单不含港澳台、成人高校。收录不代表具备研究生招生资格。
- 江苏大学：2024—2026 年共 717 条分专业、方向与学习方式的公开统计。按需更新网页，发现新年份，国家 A 线未转写为院校具体分数。统考实际录取可能含调剂，比值不等同于一志愿录取概率。
- 南京邮电大学：2023—2026 年官方分专业招生网页；查询时获取并解析，自动发现目录中的新年份。
- 南开大学：2022—2025 年计算机学院 081200 统考报名、录取数据；2025 年复试线来自学院官方公告。
- 暨南大学：2024—2026 年官方 PDF 中的分专业统计。录取口径未充分说明时不计算报录比。
- 深圳大学：安徽、广东 2024—2025 年核实快照；其余省份根据官方省份链接按需获取。只呈现解析成功且专业代码可核对的普通批记录，排除地方专项。
- 其他院校：匹配学校后直接显示官方目录入口与明确的缺项状态。考研通过研招网名称搜索补充研究院所等招生单位；高考提供阳光高考入口。北京中医药大学提供已核实的 2026 年复试线官方原文入口，其图片表格尚未转为数值。

全国普通高校**名录完整覆盖**，全国所有学校、所有专业的历年报录比与分数线**尚未完整覆盖**。部分院校没有公开报考人数，缺失项目不会估算。完整全国覆盖需要持续逐校接入，或接入获得授权的招生数据服务。

## 更新方式

网页统计与官方公告在查询时获取，服务端最多缓存十分钟。页面可见时每十分钟刷新。官方不可用或网页结构变化时保留经过核实的历史快照并提示更新状态。PDF 通过内容摘要检查变动；内容变更或出现新年份时提示需重新核对，并不自动把未经核实的数字写入历史数据。

全国名录浏览时每日最多检查一次教育部发布日与记录总数；发现变化提示，完整名录需再次导入核实。该检查不表示每条名单内容已重新验证。

没有创建定时后台采集任务。网页关闭时不会由本页面持续发起采集。检查时间与招生资料年份分开标注。

## 数据口径

每条记录均有官方来源和口径说明。南京邮电部分年份明确含推免，比例为原表报名人数/原表录取人数；南开原表明确为统考考生。不得把含推免、调剂的不同口径直接比较，也不得把复试线当作录取最低分。高考没有公开专业报名人数时不计算报录比。高考代码是本科专业目录代码，不等同于省级志愿填报代码。

## 运行

Node.js 22.13 或更高版本，使用 npm 安装依赖。

```sh
npm ci
npm run dev
npm run build
```

开发页面地址为 `http://localhost:5173`。构建完成后可通过 `npm start` 运行本地 Worker 预览，具体地址见启动输出。公共招生查询不需要 API 密钥；访问官方来源需要网络连接，来源不可用时会回退到已核实快照。

`npm run build` 生成 Cloudflare Workers 兼容输出，不是纯静态页面。GitHub 仓库托管源码，GitHub Pages 无法独立执行此项目的查询接口。使用 Sites 部署副本时，请为自己的项目重新注册网站；开源版本不包含原网站的部署标识或登录凭据。

框架是 React / Vinext，生产输出为 Cloudflare Worker。`data/snapshots.json` 保存有来源的已核实快照，`lib/admissions.ts` 实现网页解析，`lib/live-sources.ts` 实现受限官方来源更新。

## 项目结构与贡献

- `app/page.tsx`：查询界面、趋势图与招生资讯。
- `app/api/`：院校检索、招生查询与公告接口。
- `lib/`：名单搜索、官方来源读取与招生表格解析。
- `data/`：带来源的已核实名录和招生快照。
- `components/national-schools.tsx`：全国高校浏览与学校搜索提示。

欢迎通过 Issue 反馈缺失来源或解析问题，通过 Pull Request 增加院校。新增数据应附官方网址、年份、专业代码与统计口径，保留缺失值，避免用估算数字填充未公开数据。

`scripts/prepare-snapshots.mjs` 是维护用导入脚本，依赖另行下载的原始资料，日常安装与运行不需要执行它。不要提交学生个人信息、登录凭据、`.env`、依赖目录或构建输出。
